# Transportation data

Transportation data is provided by **MassDOT / MBTA**. It remains the provider's data and is not relicensed under the application's MIT license.

The bundled map is a derived subset of the public MBTA GTFS feed. Its exact archive hash, source-file hashes, retrieval date, feed coverage dates, selected stations and original source URL are in SOURCE.json and embedded in network.json. Facility descriptions in this snapshot also incorporate public MBTA API data.

A copy is included here as developers-license-agreement.pdf. This agreement requires attribution, prohibits claiming provider affiliation or ownership of its data, and supplies data without warranties. No provider logos are used.

LiftCheck is independently developed. A successful data fetch or graph calculation does not establish current physical access. The synthetic replay alerts in application code are original test fixtures, explicitly separated from official records.
